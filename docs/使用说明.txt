======================================================
 闲鱼扫货监控 · 便携版
======================================================

【怎么用】

  推荐（一个图标全搞定）：
     双击  闲鱼扫货监控.exe
     右下角出现一颗小圆点，右键就有：启动 / 停止 / 重启监控、打开界面、
     打开数据目录、打开日志文件、重新扫码登录、开机自动启动、退出程序。
     圆点颜色就是状态：绿=一切正常，黄=有要留意的，红=出问题了，灰=没在跑。

     注意「退出程序」= 真的全停了（停扫描 + 停守护 + 关浏览器内核 + 去图标），
     数据不会丢，想再开始就重新双击 闲鱼扫货监控.exe。如果只是不想看到图标、
     想让扫描继续跑，那就别点它，直接关掉托盘那个 powershell 窗口即可。

  搬家到新电脑：
  1. 把整个文件夹拷过去（U 盘 / 移动硬盘 / 网盘都行）
     建议放在不含中文和空格的路径，例如  D:\xianyu-monitor

  2. 双击  闲鱼扫货监控.exe
     第一次启动会自己找 runtime\ 里的 node 和浏览器，不用装任何东西。

  3. 浏览器会自动打开界面： http://127.0.0.1:59288/
     没自动开就右键托盘图标 →「打开监控界面」。

【启动之后先「待命」，点一下才开始扫】

  双击 闲鱼扫货监控.exe 之后，程序是「醒着但不动网」的状态：浏览器开着、
  登录态就绪、面板能打开，但一个搜索请求都不会发。日志里会看到：

      ⏸ 已进入待命：不会发出任何搜索请求。
        启动模式：待命（startMode=hold）

  要真正开始扫，点下面任意一处：
      · 面板右上角工具栏  「▶ 开始监控」
      · 托盘右键菜单      「▶ 开始监控」
      · 待命时列表顶部的蓝色横幅里那个「开始监控」按钮

  点下去日志立刻出现  ▶ 已解除待命，开始扫描。   然后  --- 第 1 轮 ---
  待命不会过期，放一整天也不会自己开始扫。

  唯一入口就是 闲鱼扫货监控.exe（托盘）。它启动后停在待命，
  这样开机自启不会自己动网，你想扫的时候点一下就行。

  想改成「启动就扫」（老行为）：把 config.json 里的
      "startMode": "hold"     改成   "auto"
  或者在面板「筛选设置」最下面「启动与节奏」里选「自动开始」。

  来回点「开始 / 暂停」不会增加风控风险——点按钮本身不发任何请求。
  但别在一两分钟内反复连点（每点一次就多跑一轮）。所以默认有连点保护：
  距上一轮不足 180 秒时会自动顺延，连点十次也只跑一轮。
  嫌它烦就把 config.json 里的 "resumeMinGapSec" 改成 0。

【登录态】


  · 本便携版已经带上 data\cookies.json，理论上换电脑不用重新扫码。
  · 但如果打开面板看到顶部有【红色横幅：登录已失效】，
    或者「接口最新一条」显示好几个小时前，说明 cookie 在新机器上失效了：
      → 点横幅上那个大红按钮「立即重新登录并恢复」
      → 或者双击  3-重新登录并恢复.cmd
      → 在弹出的浏览器窗口里用手机扫码登录，之后全自动

【新电脑需要什么】

  · Windows 10 / 11（64 位）
  · 不需要装 Node.js —— runtime\ 里自带
  · 不需要装浏览器 —— runtime\playwright-browsers 里自带
  · 不需要联网下载任何东西

【目录里都是什么】

  闲鱼扫货监控.exe                推荐日常入口：右下角常驻小圆点，右键启停
  托盘.ps1                托盘本体（由 闲鱼扫货监控.exe 调它，不用直接点）

  3-重新登录并恢复.cmd     登录过期时用：停监控 → 扫码 → 存 cookie → 自动重启
                          （面板「登录 / 换号」按钮也是调它，平时不用手动点）
  0-首次扫码登录.cmd       只做扫码登录，不重启监控（第一次装的时候用）

  monitor.cjs             核心监控程序
  login-manual.cjs        扫码登录用
  config.json             你的筛选条件、扫描间隔、端口
  regions.json            省市联动数据
  panel\                  界面（index.html + inject.js）
  runtime\                node.exe + playwright + 浏览器内核（790 MB，必需）
  runtime.txt             运行时位置指针（拷走后会自动改用本目录的 runtime\，不用改）
  data\                   你的记录、登录 cookie、屏蔽名单、日志
  docs\维护手册.md         出问题怎么查（含症状对照表）

【data\ 里几个关键文件】

  hits.json               你的命中记录（带过来了，一个不丢）
  seen.json               已见过的商品 ID（带上才不会把老货当新货重推）
  cookies.json            登录态
  deep-state.json         基线签名（带上才不会重翻 50 页）
  seller-blocklist.json   你屏蔽的商贩名单
  word-hits.json          屏蔽词命中统计
  monitor.log             运行日志（新机器重新记）

  注意：没有带 data\browser-profile\
        那是浏览器缓存（原体积 691 MB，其中 676 MB 是纯缓存）。
        新机器第一次启动会自动重建，约 17 MB，不影响登录态。

【出问题怎么办】

  最短路径：面板右上角点【体检】。
    它把 10 项挨个查一遍（登录 / 扫描进度 / 接口鉴权 / 平台限流 / 数据质量 /
    浏览器内核 / 数据文件 / 基线重建 / 推送 / 守护进程），全部只读，
    不发搜索请求、不改数据，几秒钟出结果，还告诉你下一步该干什么。

  详细的排查步骤见 docs\维护手册.md
  （睡眠空窗、重建基线、被限流、闲鱼改接口，都有对应章节）

  · 界面打不开、提示"面板脚本加载失败"
      → 监控没跑起来，双击 闲鱼扫货监控.exe（或托盘菜单「启动监控」）

  · 双击后一闪就没了
      → 在命令行里进到这个目录手动执行：
           runtime\playwright-driver\node.exe monitor.cjs
        看报什么错

  · 一直显示"最新一条是 X 小时前"
      → 登录态失效，按上面【登录态】那段重新登录

  · 提示"被平台限流 / 被挤爆啦"
      → 程序会自动退避（5 分钟 → 10 分钟 → 20 分钟），不用管
        别急着反复重启，每次重启都会把冷却窗口重新续上

  · 端口 59288 被占用
      → 改 config.json 里的 "port"，三个启动脚本会自己读它
